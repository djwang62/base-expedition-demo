# 基地探索｜Playable Demo

> [立即遊玩](https://djwang62.github.io/base-expedition-demo/)

《基地探索》是一款以原生 JavaScript 與 HTML5 Canvas 製作的單人動作探索遊戲原型。玩家從中央基地出發，探索森林、山脈與礦場等生態域，擊敗敵人蒐集資源，逐步建造基地設施、製作與強化武器，最終挑戰外圈 Boss。

## 操作方式

| 動作 | 操作 |
| --- | --- |
| 移動 | WASD 或方向鍵 |
| 衝刺 | Shift 或畫面右下角按鈕 |
| 設施互動／建造 | 靠近基地設施後按 F |
| 背包 | Tab 或左上背包按鈕 |

## Demo 範圍

- 三圈生態域、守衛解鎖與外圈 Boss 戰。
- 基地建設、資源蒐集、武器製作與強化。
- 目前不提供跨工作階段存檔；重新整理頁面會重置本次進度。

## 技術與素材

- 以 JavaScript、HTML5 Canvas 與 Vite 建置。
- 本 repository 僅包含可公開遊玩的建置成品，不含原始開發歷史或工作檔。
- 遊戲視覺素材使用 Codex 生成並由專案作者整合。
